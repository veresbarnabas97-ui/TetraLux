## 🚀 About TetraLux

TetraLux (TLX) is an ethical, community-driven decentralized finance (DeFi) ecosystem built on the Solana blockchain. Designed for long-term stability and sustainable passive income, TetraLux integrates transparent on-chain presale mechanisms, yield-boosting governance NFTs (**TetraDiamond**), and robust liquidity structures.

### Key Features
- **Solana Speed & Low Fees:** High-performance transactions powered by Solana.
- **Transparent Presale:** Direct interaction via Anchor smart contracts.
- **TetraDiamond NFTs:** Exclusive utility membership offering an additional +10% staking yield boost, revenue sharing, and governance rights.
